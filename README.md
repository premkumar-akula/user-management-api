# User Management REST API

A robust REST API for managing users built with Node.js, Express, and SQLite.

## Features

- ✅ Full CRUD operations for users
- ✅ Search functionality across name, email, and city
- ✅ Sorting by any field (id, name, email, age, city, created_at)
- ✅ Input validation and error handling
- ✅ SQLite database for persistent storage
- ✅ Auto-initialization with sample data
- ✅ CORS enabled

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
